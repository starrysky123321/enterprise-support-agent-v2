# 本地评测

## 2026-11-21：拒答改进与扩大后的对照

本轮用同一份 **174 篇、355 个分块、357 题**的英文合成资料，对比 Git 版本 `2a8bea70f68cfaed6532a43b81b8ff9befee9374` 与当前实现。包含 281 道可回答题、69 道语义无答案题、7 道权限题。回答使用 `local-extractive-v1`，不调用 Qwen。底部保留早期评测，历史小题集的百分比不代表本轮结果。

本轮数据由原 63 题、122 题难例、124 题原 holdout、48 题新增验证组成。原 holdout 的失败已经用于分析，因此现在属于开发回归集。新增验证为新服务名与新错误码的对照题，生成后不调阈值；曾在修复原题问法回归后重跑，属于窄范围确认测试，不是外部盲测。全部语料在两次运行中相同；不能将旧报告的小语料结果与新语料直接作差。

### 标签复核

完整语料中，`holdout-none-108` 的 archiver 队列容量已经明确为 380，`holdout-none-115` 的生产追踪采样比例已经明确为 5%。这两题应为可回答。修正记录与引文见 [reviewed_labels.json](../eval/reviewed_labels.json)，通过 `--review-labels` 对改动前后同时应用，保留原始题文件以便复现旧报告。修正后原 holdout 有 102 道可回答、22 道无答案题。

### 实现变化

- 将省略连字符的 `CFG5120` 等编号归一为 `CFG-5120`，对证据中的编号使用完整边界匹配，防止相似编号借用定义。
- 对服务、会话、队列、`per gateway` 等显式对象及所问属性分别检查，减少把同服务的 payload 当成重试次数、把每租户限制当成每网关限制的情况。
- 日期、时长、频率、端口、百分比、时刻、数量、HTTP 状态码等查找要求相应形式的证据。逐分块判断词语/语义相关性，再查所需值，避免从另一个分块借相似度或编号。
- 多个问句分别找支持，任一必需子问题无证据时拒答；原权限范围内仍最多检索两次。普通单文档回答复用证据检查，并更新缓存版本。

以上是本地抽取路径的启发式证据检查，不是事实蕴含证明。语义阈值 `0.60/0.57` 只在当前 BGE/Chroma L2 设置下校准，不是正确率；更换模型、向量距离或语言后必须重新验证。Qwen 路径仍依赖提示与引用 ID 完整性校验，本轮没有证明它的事实级拒答能力。

### 回答结果

以下每题只计一次 Agentic 回答。正确拒答以语义无答案题为分母，误拒以可回答题为分母；权限题单列，不把无可读文档混入语义拒答。JSON 中跨文档 API 的原始汇总仍含一个权限范围为空的案例，因此该汇总是 65/65；这里全部 69 个语义无答案案例由单文档 5 个与跨文档 64 个组成。

| 题集 | 正确拒答，改动前 → 后 | 误拒，改动前 → 后 | 参考事实覆盖率，改动前 → 后 |
| --- | ---: | ---: | ---: |
| 原 63 题 | 7/7 → **7/7** | 0/49 → **0/49** | 96.9% → 94.9% |
| 122 题难例开发集 | 2/10 → **10/10** | 17/112 → **9/112** | 72.3% → 85.7% |
| 原 holdout，现开发回归集 | 5/22 → **22/22** | 15/102 → **7/102** | 75.5% → 85.3% |
| 48 题新增验证集 | 0/30 → **30/30** | 0/18 → **0/18** | 100.0% → 100.0% |
| 全部 357 题 | 14/69 → **69/69** | 32/281 → **16/281** | 79.5% → 88.1% |

新增验证集的 30/30 正确拒答，Wilson 95% 区间为 **[88.6%, 100%]**；18 道可回答题误拒 0/18，区间为 **[0%, 17.6%]**。全量正确拒答 69/69 的区间为 [94.7%, 100%]。全量误拒从 11.4% 降至 5.7%；逐题配对 bootstrap 的差值区间为 [-9.6, -1.8] 个百分点。全量参考事实覆盖率提升约 8.5 个百分点，但原 63 题覆盖率从 96.9% 降到 94.9%，说明证据筛选仍有局部损失。单文档两条路径均正确拒答 5/5，误拒 0/37，单文档参考事实覆盖率为 97.3%。所有检索与回答路径均未返回超权限范围文档，单文档拒绝访问均为 6/6。

还剩 **16/281 个误拒**，主要来自同义改写。失败 ID 全部保留在 [统计快照](refusal-evaluation.json) 的 `remaining_failures` 中。例如 `hard-para-04` 将 traffic records 改写为 access logs，`holdout-para-09` 将 staging replica 改写为 shadow environment，目前无法稳定通过检查。已经检验过这些失败后，不再将它们当未知测试集。回答未拒绝也不等于完整答对，仍需查看引用和事实覆盖。

### 检索与重排

检索在 281 个可回答题上计算逐题均值；95% 区间采用 10,000 次问题级 bootstrap，固定随机种子 20261121。二元拒答/误拒使用 Wilson 区间，避免全对时 bootstrap 给出没有信息的 [100%, 100%]。模板之间相关，问题级区间可能偏乐观，均不能推断真实工单分布的效果。

| 模式 | Recall@5 [95% 区间，%] | MRR@5 [95% 区间] |
| --- | ---: | ---: |
| BM25 | 79.7% [75.1, 84.3] | 0.6889 [0.6418, 0.7364] |
| Dense | 83.1% [78.8, 87.4] | 0.7351 [0.6883, 0.7807] |
| Hybrid RRF | 89.0% [85.4, 92.5] | 0.8107 [0.7691, 0.8513] |
| Hybrid + Cross-Encoder | 89.9% [86.3, 93.2] | 0.8301 [0.7897, 0.8695] |

Hybrid 相比 BM25 的 Recall 提升 **9.25 个百分点**，配对区间 [+6.05, +12.81]；相比 Dense 提升 5.87 个百分点，区间 [+1.96, +9.79]。重排相比 Hybrid 的 MRR 提升 0.0194，区间 **[-0.0087, +0.0482]**，扩大语料后再次无法证明稳定收益；Recall 差值区间也包含 0。保持可选/可降级定位。这个结论不能与此前 161 题上 MRR +0.046 的结果混用：题集与检索语料都扩大了。回答对照仍统一使用 Hybrid RRF，不使用重排；这里没有把重排收益算成拒答改进。 两次使用独立临时 Chroma 索引，少数无答案题候选顺序有变化（Dense 3 题、Hybrid 5 题、重排 1 题，BM25 无变化）；全部可回答题的逐题检索指标一致。变化 ID 见统计快照的 `retrieval_run_differences`。这是端到端系统对照，未固定每一步候选，不是仅替换证据检查函数的严格消融。

## 评分口径

- **检索**以可回答案例为分母，扩展集 49 题，原基线 40 题。Hit@5 表示前五个分块是否包含任一标注分块，Recall@5 表示找回的标注分块比例，MRR@5 衡量第一个标注分块的排名。
- **回答**经过 FastAPI 路由、真实权限判断和对应的 Agent 流程。单文档对照向两条问答路由提交同一个 `doc_id`，扩展集共 48 题。其余 15 题由支持省略 `doc_id` 的 Agentic API 处理，仍然应用权限与版本过滤。原基线对应 39 题和 11 题。
- **引用**以 API 实际返回的去重分块为输入。标注引用精度统计与标注分块匹配的引用比例，缺引用时计 0。参考事实覆盖率要求标注短引文同时出现在回答与对应引用片段中。两项均在可回答案例上计算。普通 RAG 会返回检索工具给出的证据，Agentic RAG 返回在回答中使用的引用。这是固定证据对照，完整事实正确性与改写后的语义一致性需要单独复核。
- **权限与拒答**用实际返回的 404 和业务拒答分别计分。误拒率以可回答用例为分母，统计其中的拒答比例。测试身份通过进程内依赖注入，权限、部门和空间成员关系从数据库读取。检索结果或引用落在允许范围之外会使评测失败。此评测验证文档访问规则，登录和 Token 校验由其他测试覆盖。
- **延迟**使用预热后逐题串行的本地 P95。检索时间不含预先算好的权限范围，回答时间包含进程内 ASGI 和权限查询。回答组使用同一条 Hybrid RRF 检索路径，关闭语义缓存和普通 RAG 查询重写。

## 2026-11-18 证据检查改动前的基线

Linux x86_64，Intel Core Ultra 7 255HX，CPU 执行本地模型，OMP 和 MKL 均为 2 线程。向量模型为 BGE-small-en-v1.5，重排模型为 MS MARCO MiniLM-L6-v2，回答使用本地抽取模式。

| 检索模式 | Recall@5 | MRR@5 | 本地 P95 |
| --- | ---: | ---: | ---: |
| Dense | 96.25% | 0.9688 | 14.62 ms |
| BM25 | 98.75% | 0.9875 | 0.85 ms |
| Hybrid RRF | 98.75% | 0.9875 | 15.04 ms |
| Hybrid RRF + Cross-Encoder | 98.75% | 0.9563 | 126.75 ms |

| 回答路径 | 标注引用精度 | 参考事实覆盖率 | 正确拒答 | 单文档拒绝访问 | 本地 P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通 RAG，同一文档对照 | 35.42% | 100% | 0/4 | 3/3 | 22.10 ms |
| Agentic RAG，同一文档对照 | 52.08% | 96.88% | 0/4 | 3/3 | 25.54 ms |
| Agentic RAG，按权限跨文档 | 50.00% | 81.25% | 2/3 | — | 45.94 ms |

四种检索模式与两条回答路径均未返回超范围文档。Hybrid RRF 与 BM25 在本批题中召回持平。两者都在 `rate-origin` 漏掉一条所需证据；重排未补回，首条相关证据的平均排名表现也下降。在单文档对照中，两条回答路径都未正确拒答 4 个无答案问题，例如问欧盟租户紧急限流豁免时长时，系统返回了通用限流段落。现有关键词相关性与引用校验无法判断片段是否足以回答具体问题。

结果来自小规模、单产品、英文合成数据，主要用于检查行为和定位失败。中文分词、真实工单分布、远程生成模型和生产延迟需要单独评估。

## 证据检查改动后的复测

题集、语料和 BGE/Cross-Encoder 参数与上面的基线一致。问答继续使用本地抽取模式，另用默认哈希向量跑了一遍链路。新规则要求涉及默认超时、时长、日期、命令和表名的显式查询找到相应类型的证据。缺少证据时，Agentic 路径会在原权限范围内按上限重试。规则依赖原文的表达方式，完整的事实级语义核验需要独立验证。

| 回答路径 | 正确拒答，改动前 → 后 | 复测误拒 | 参考事实覆盖率，改动前 → 后 |
| --- | ---: | ---: | ---: |
| 普通 RAG，同一文档对照 | 0/4 → 4/4 | 0/32 | 100% → 100% |
| Agentic RAG，同一文档对照 | 0/4 → 4/4 | 0/32 | 96.88% → 100% |
| Agentic RAG，按权限跨文档 | 2/3 → 3/3 | 0/8 | 81.25% → 81.25% |

跨文档组的 3 个拒答案例包含 2 个无答案问题和 1 个无可读文档的权限案例。两种问答路径均未返回超范围文档。跨文档组的标注引用精度由 50.00% 降至 43.75%，因为其中一题附带了额外的队列排障片段。覆盖率保持一致，跨文档证据筛选仍有改进空间。
